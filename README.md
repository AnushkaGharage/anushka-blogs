## 🎯 **Course Overview**

This comprehensive course teaches you to create professional websites and blogs directly from your GitHub repositories using GitHub Pages. No web development experience required!

**What You'll Learn:**
- ✅ Enable GitHub Pages for any repository
- ✅ Choose and customize themes using configuration files
- ✅ Master Jekyll directory structure and naming conventions
- ✅ Create engaging blog posts with proper formatting
- ✅ Deploy live websites with automatic updates

## 📋 **Quick Reference**

### **Essential Commands**
Clone your pages repository
git clone https://github.com/username/username.github.io.git

Create a new post
touch _posts/2025-11-02-my-new-post.md

Local development (if using Jekyll locally)
bundle exec jekyll serve

Deploy changes
git add .
git commit -m "Add new content"
git push origin main


### **File Structure**
your-site/
├── _config.yml # Site configuration
├── _posts/ # Blog posts
├── _layouts/ # Page templates
├── _includes/ # Reusable snippets
├── assets/ # CSS, JS, images
├── index.md # Homepage
└── README.md # Repository documentation
